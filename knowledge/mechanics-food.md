# Механика: пища, эгрегор, переедание

Сжатая рабочая модель для советов. Развёрнутый конспект под контур: `pohudenie/egregore-gluttony.md`.

## Разделение

| Слой | Суть | Опора в корпусе |
|------|------|-----------------|
| Пищевой фактор / пищевой эгрегор | Матрица выживания; первый виток спирали; из тела не выйти | `167_178`, `168_179` |
| Хозяин переедания | Вредная привычка-яма; служба за эйфорические гормоны | `187_198` |
| Вкусовая матрица | Соль/сахар/кулинария как самообман и лёгкий наркотик; штрафной круг | `167_178`, `182_193` |
| Эйфорический ноль | Всплеск компенсируется спадом; голод усиливает эйфорию от простой еды | `012_13` |
| Хлеб и зрелища | Рациональный канал еды подменяет эмоциональный голод | `112_123` |
| Ритуал ↔ эгрегор | Внимание и эмоции кормят связь; взамен краткий «руль» | `003_4`, `091_101` |

## Практический вывод для аскетизма

- Тяга «хочу вредное» при сытости — хозяин привычки, не пищевой фактор.
- Разрыв канала: новый хозяин (цель, режим, силовая) + замена равного эмоционального заряда; голый запрет копит срыв.
- Неделя простой еды — лишение вкусовой матрицы; шум желаний ожидаем как плата за выход из ямы.
- После разгрузки не оставлять монодиету второй ямой: достаточный простой рацион без вкусового мусора.
