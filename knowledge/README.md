# База знаний проекта

Память агента и договорённости по репозиторию asuri (рассылка + личный контур похудения).

## Индекс

| Файл | Содержание |
|------|------------|
| `voice.md` | Голос автора рассылки; Caveman выключен |
| `pohudenie-context.md` | Сводка личного контура 127→89 кг |
| `mechanics-food.md` | Пищевой эгрегор, хозяин переедания, эйфорический ноль |
| `corpus-map.md` | Карта ключевых выпусков `rassylki/` для опоры |

Оперативные протоколы дня, меню, упражнения — в `pohudenie/` (не дублировать здесь целиком, только ссылки и устойчивые выводы).

## Правила обновления

1. Новая устойчивая договорённость с пользователем → запись сюда в тот же ход (и коммит в рабочую ветку).
2. Изменение профиля / режима / рациона → правка `pohudenie/` + короткая пометка в `pohudenie-context.md`, если меняется рамка.
3. Выводы из рассылки, которые начинаем применять постоянно → `mechanics-*.md` или `corpus-map.md`.
