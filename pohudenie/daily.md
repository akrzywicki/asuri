# Ежедневный контур

Формат работы с ассистентом: каждый день — вопросы + план на день. Ответ ассистента опирается на `README.md`, `menu.md`, `regime.md`, `schedule.md`, `tracker.md`.

## Что присылать утром (шаблон)

```
Дата:
Вес (если день замера):
Сон (часы / качество 1–5):
Колено (0 тихо / 1 ноет / 2 стоп):
Шаги или минуты ходьбы вчера:
Силовая вчера (A / B / нет):
Еда вчера (чисто / срыв + что):
Вопрос:
Запрос на план сегодня:
```

День замера веса — один раз в неделю, утром натощак (см. `tracker.md`).

## Что возвращает ассистент

1. План дня: еда (завтрак / обед / ужин / добор), ходьба, силовая или отдых.
2. Ответы на вопросы в рамках огненного аскетизма и ограничений по колену.
3. При необходимости — правка файлов в `pohudenie/` и запись в журнал.

## Жёсткие рамки дня

- Бег и прыжки — нет.
- Ходьба — да.
- Силовая — дом + турник с резиной, по сетке A/B из `regime.md` (на неделе 0 — облегчённо, см. `unload-week.md`).
- Еда — на неделе 0: `unload-week.md` (гречка + кефир); далее корзина из `menu.md`.
- Срыв — следующий приём чистый, без голода «в наказание».
- Разгрузку гречка+кефир не продлевать дольше 7 дней.
