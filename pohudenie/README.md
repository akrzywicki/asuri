# Похудение: огненный аскетизм

Личный рабочий контур снижения веса. Принцип: дефицит калорий через упрощение рациона, регулярную нагрузку и отказ от пищевого шума.

## Профиль

| Параметр | Значение |
|----------|----------|
| Пол | мужской |
| Возраст | 34 |
| Город | Балашиха |
| Работа | разработчик, удалённо (сидячий режим) |
| Рост | 176 см |
| Вес старт | 127 кг (2026-07-25) |
| ИМТ старт | 41.0 |
| Цель | 89 кг |
| ИМТ цель | 28.7 |
| К снижению | 38 кг |
| Горизонт | 9–12 мес (огненный план ≈ 40 нед → ~2027-05) |
| Нагрузка | ходьба + турник + упоры для отжиманий + гиря 6 кг |
| Ограничения | без бега/прыжков: ПКС, нестабильность колена, Шляттер в анамнезе |

Талию при старте ещё не замерили — первая запись в `tracker.md` после появления ленты.

Подробный график фаз и вех: `schedule.md`.

## Правила

1. Еда насыщает, не развлекает.
2. Белок на каждый приём; овощи без лимита; крупа — одна порция днём.
3. Сахар, сладкие молочные продукты, колбаса, соусы с сахаром, снеки — вне рациона.
4. Замеры: вес и талия один раз в неделю, в одно и то же утро.
5. Срыв закрывается следующим чистым приёмом пищи, без компенсации голодом.

## Порции (ориентир)

- Белок: размер ладони (150–200 г готового мяса/рыбы или 150 г творога / 3 яйца).
- Крупа сухая: 60–70 г на обед.
- Жир: 1 ч.л. масла на приём.
- Овощи: без ограничения по объёму.

## Медицинское ограничение

При хронических заболеваниях, лекарствах или ИМТ вне рабочей зоны план согласуется с врачом до старта.
