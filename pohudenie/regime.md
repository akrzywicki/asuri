# Режим: нагрузка и ритуалы

## Ограничения по колену

Диагноз/анамнез (самоотчёт): травма крестообразной связки, повышенная нестабильность сустава, синдром Осгуда–Шляттера в подростковом возрасте.

Следствия для плана:

- Бег, прыжки, выпады в глубину, берпи, резкие смены направления — вне программы.
- Приседания только в безболезненной амплитуде; при дискомфорте — заменить на ягодичный мост / стул к стене с малой глубиной.
- Поверхность для ходьбы: ровная; избегать скользкого и сильного уклона на старте.
- Боль, отёк, ощущение «вывихивания» — стоп упражнения на ноги в этот день; при повторении — очная консультация травматолога/ЛФК.

Кардиодефицит закрываем **прогулками**, не бегом.

## Приоритеты движения

1. Ежедневная ходьба.
2. Домашние упражнения с весом тела.
3. Турник на этаже: подтягивания с резиной-помощником (полные подтягивания — цель навыка, не старт).

Инвентарь: пол / коврик, турник, резиновая лента для облегчения подтягиваний. Зал не обязателен.

## Ходьба (ежедневно)

- Цель: 8–10 тыс. шагов или 45–60 минут суммарно.
- Дробить на 2–3 выхода между созвонами допустимо и желательно.
- Темп: быстрый шаг без хромоты и без боли в колене; если колено ноет — укоротить выход, не ускорять.
- Каждые 45–60 минут за компьютером — встать на 2–3 минуты (проход по квартире).

## Силовая: 3–4 раза в неделю

Длительность сессии: 25–40 минут. Схема A/B, чередование.

Общие правила: медленный контроль, без рывков; 60–90 сек отдых между подходами; дыхание ровное. На старте 127 кг техника важнее числа повторов.

### Блок A (акцент верх + задняя цепь)

| Упражнение | Доза | Примечание |
|------------|------|------------|
| Подтягивания с резиной | 3–5 × 4–8 | Резина к турнику, колено/стопа в петлю; тяга грудью к перекладине |
| Отжимания (от пола / от стола / от стены) | 3 × 6–12 | Уровень: где техника чистая |
| Ягодичный мост двумя ногами | 3 × 10–15 | Без боли в колене; таз вверх, пауза 1 сек |
| Планка на предплечьях | 3 × 20–40 сек | Если давление на колени мешает стойке на четвереньках — только планка/мертвый жук |
| «Мертвый жук» (dead bug) | 3 × 6–8/сторона | Поясница прижата к полу |
| Лодочка / сведение лопаток лёжа на животе | 3 × 10–12 | Верх спины, без гиперэкстензии поясницы |

### Блок B (акцент турник + корпус + ноги без удара)

| Упражнение | Доза | Примечание |
|------------|------|------------|
| Подтягивания с резиной (или австралийские, если появится низкая перекладина) | 3–5 × 4–8 | Та же прогрессия, что в A |
| Отжимания узким упором или обычные | 3 × 6–12 | Локти ~45° к корпусу |
| Стул у стены (wall sit) | 3 × 15–30 сек | Глубина малая; стоп при боли в бугре большеберцовой / связке |
| Подъём таза / ягодичный мост | 3 × 10–15 | Альтернатива при отказе от wall sit |
| Боковая планка с колен (облегчённая) | 3 × 15–25 сек/сторона | Без боли |
| Вис на турнике (плечи активны) | 3 × 10–20 сек | Расслабление хвата + плечи вниз от ушей |

### Прогрессия подтягиваний

1. Вис + лопаточные подтягивания (scapular pull-ups) 3 × 5–8.
2. Подтягивания с толстой/сильной резиной, 4–8 чистых повторов.
3. Более слабая резина, когда 3×8 даются легко.
4. Негативные опускания 3–5 сек (только если колено и плечи позволяют залезть с опоры без прыжка).
5. Полные подтягивания — когда негативы и слабая резина стабильны.

Прыгать к перекладине с пола при нестабильном колене не нужно: использовать стул/опору для входа в вис.

### Разминка перед силовой (5 минут)

- Круги плечами, вращения руками.
- Лёгкие подъёмы колен на месте без пружины (марширование), 1–2 минуты.
- Приседания к стулу до касания сиденья — 8–10 раз, только без боли.
- 1 подход отжиманий от стены / столa.

## Чего не делаем

Бег, скакалка, прыжки на тумбу, глубокие выпады, пистолетики, резкий спуск по лестнице «бегом», игровые виды с разворотами. Лестница в доме — спокойный шаг, опционально, по самочувствию колена.

## Сон

- 7–8 часов.
- Последний час перед сном без экрана по возможности.

## Утренний ритуал (фиксированный порядок)

1. Вода.
2. Ходьба или короткая силовая (блок A или B).
3. Завтрак.

Порядок не обсуждается в моменте: решение уже принято планом.

## Недельный каркас

| День | Нагрузка |
|------|----------|
| Пн | Силовая A + ходьба |
| Вт | Только ходьба |
| Ср | Силовая B + ходьба |
| Чт | Только ходьба |
| Пт | Силовая A + ходьба |
| Сб | Силовая B (или лёгкая A) + ходьба |
| Вс | Ходьба, без силовой; колено разгрузить |

После сессии — прохладный или контрастный душ по переносимости.

## Еженедельный контроль

- Один утренний замер натощак: вес, талия → `tracker.md`.
- В заметке трекера коротко: число силовых сессий, шаги/минуты ходьбы, сигналы колена (0 = тихо, 1 = ноет после, 2 = стоп).
- Корректировка еды — по тренду веса 2+ недель; корректировка нагрузки на ноги — по сигналам колена в тот же день.
