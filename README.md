# Энергетика Взаимоотношений (asuri.ru)

Сборник статей сайта asuri.ru.

**О чем эти статьи?**
Эти статьи представляют собой практическую психологию и социальную философию, упакованные в эзотерическую терминологию. Автор использует понятия вроде эгрегоров, энергообмена и нейронных связей как функциональные модели для объяснения поведения людей. В текстах много здравого смысла, логики и точных наблюдений за бытовыми ситуациями, отношениями и механизмами мотивации. Эзотерический язык служит здесь инструментом для структурирования сложных психологических процессов.

Воспринимайте эти материалы как альтернативный аналитический взгляд на человеческие взаимоотношения.

## Рассылки в репозитории

Файлы рассылок лежат в каталоге `rassylki/`.

**Именование:**

- формат имени файла `NNN_{номер}-{slug}.md`: три цифры `NNN` (от `001`), символ `_`, номер выпуска (как в архиве рассылки) и тематический хвост в slug (слова через дефис, в этой копии текстов преимущественно кириллица);
- `NNN` задает порядок в оглавлении: значение выводится после сортировки по паре основной номер выпуска и при необходимости подномер подвыпуска (`{M}-{k}-...`);
- несколько текстов одного выпуска: к номеру выпуска добавляется второй блок через дефис, например `29-1-...`, `44-1-...`.

**Скрипт перенумерации префикса:** `scripts/reorder_rassylki.py`.

- без аргументов: печать предлагаемых команд `git mv` (перенос только блока до первого `_`);
- ключ `--apply`: двухэтапное переименование через временный каталог `rassylki/.rename_stage_rassylki/`, сохраняя историю в git при использовании `git mv`.
